# ROG 枪神9 超低功耗模式

出门前点一下，整机功耗压到 13.7W，续航从 3 小时变 5.3 小时。回来点一下，完全恢复。

专为 **ASUS ROG 枪神9 / G615LR**（魔霸新锐 2025）写的。

<img src="https://img.shields.io/badge/实测-13.7W%20%2F%205.3h-brightgreen" alt="">

## 为什么需要它

枪神9 待机功耗本来就高，出门半天电就没了。开着游戏本的习惯改不掉，但**不用时可以把它当电池用**。

这个工具一键把所有吃电的地方一起关掉：CPU 锁频、屏幕降到 60Hz、屏幕压暗、独显直接断电。不是「省电模式」那种砍一点，是**把整机当成没有独显的轻薄本来用**。

## 安装

1. 去 [Releases](../../releases) 下载 `UltraLowPower-Setup.exe`（53 KB，单文件）
2. 双击，UAC 弹窗点「是」
3. 完成

不用装任何东西。

> Windows 会弹「Windows 已保护你的电脑」——这程序是我自己编译的，没买签名证书。
> 点 **更多信息 → 仍要运行**。

## 用法

装好之后桌面上有个图标，两件事：

- **开启超低功耗模式** —— 出门前点一次
- **退出并恢复** —— 回来后点一次，或者到地方了就点一次

界面每 3 秒刷新当前功耗和预计续航，可以看着它降。

## 效果

在 Core Ultra 9 275HX + RTX 5070 Ti + 72.8Wh 这台机器上实测：

| | 功耗 | 续航 |
|---|---|---|
| 开着这个工具，动态壁纸关掉 | **13.7W** | **5.3 小时** |
| 开着这个工具，动态壁纸开着 | 24W | 3.0 小时 |

**13.7W 是这台机器这一次测出来的，不是产品标称。** 换配置请看界面上的实时读数。

> 差距的大头是**动态壁纸**，不是 CPU 锁频。Wallpaper Engine 在 2560×1600 上跑动画，吃 56% CPU 还带 iGPU，比 CPU 锁频、亮度、独显断电加起来影响都大。出门前顺手关掉，比什么优化都管用。

## 它做了什么

- 所有电源方案一起锁定 **15 项**设置：CPU 频率上限 1GHz、只用 2 个核心、禁用睿频、屏幕 20% 亮度、PCIe 省电、USB 省电、Wi-Fi 省电
- 刷新率降到 **60Hz**
- 独显切核显，**直接断电**
- 开启前把所有原值存进 `backup.csv`，退出时**一项一项读回来**

独显切换是硬件开关，**要重启才生效**。重启之后你再打开一次这个工具，它会自己把剩下的步骤补完，不用再点。

## 能用在什么机器上

在 **枪神9 / G615LR** 上全部可用。同系列的 G615LR / LW / LP / LM / JH / LH 应该都行（同一个平台，差异只在 CPU 和显卡型号）。

别的机器：

- 电源方案那 15 项、刷新率 —— **任何 Win10/11 笔记本都能用**（用的都是微软标准 GUID，没有写死）
- 独显断电 —— **只有华硕能用**。别的牌子会跳过，然后明说 `ATK 接口不可用`，不会假装成功

## 卸载

「设置 → 应用 → 已安装的应用」里找到它点卸载。

**卸载的时候如果超低功耗模式还开着，它会先把电源设置恢复回来再删文件**——不会把你的 CPU 永久锁在 25%。

## 自己编译

只要 Windows 自带的 PowerShell 和 `csc`（.NET Framework 自带的编译器），不需要装任何第三方打包器。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File installer\build.ps1
```

## 说明

- 开启期间别启动游戏或用独显的软件，会把独显叫醒，功耗就上去了
- `backup.csv` 是恢复的唯一依据，`state.json` 记录剩余的还原信息，**别删**（正常点「退出」会自动清掉）
- 搬动或重命名安装目录 = 丢掉还原依据，会被锁在 25% 出不来
- 键盘灯跨重启自动关**做不到**（开机点灯的是固件，Windows 侧关不掉），所以没做这个功能
- 用了 Armoury Crate（奥创中心）也不冲突，两边可以共存
